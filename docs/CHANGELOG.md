# Журнал версий

## silikbox 1.0.0 — 19.11.2026

- Добавлен **VLESS XHTTP / SplitHTTP** через встроенный Xray-core 26.11.9. Android VPN, DNS и маршрутизацию обслуживает sing-box 1.14.4-silikbox.3.
- Импорт и экспорт VLESS XHTTP-ссылок 3x-ui сохраняют Host, путь, режим, параметры TLS/REALITY и поддерживаемые поля `extra`.
- На физическом Infinix с Android 11 проверен **VLESS + XHTTP + REALITY с 3x-ui на публичном 443**. Через Android VPN получен 1 МиБ по HTTPS с кодом 200.
- Подписанный релиз для ARM64 имеет versionCode 280 и сохраняет идентификатор и сертификат прежних сборок.

**[Скачать APK и отчёт проверки](https://github.com/silikonoff/silikbox/releases/tag/v1.0.0)**

## silikbox 1.0.0-alpha3 — 16.11.2026

- Добавлен резерв поиска адреса VPN-сервера: **Google DoH → обычный DNS Cloudflare → системный DNS Android**. Этапы ограничены по времени; в настройках можно отключить резерв или только системный этап.
- Запросы сайтов и пользовательские правила сохраняют прежнюю DNS-политику. Резерв ограничен A/AAAA-запросами имён серверов текущей конфигурации; явные resolver-параметры и полные пользовательские конфигурации сохраняются.
- AliDNS удалён из APK и настроек по умолчанию. Прежние стандартные адреса распознаются по SHA-256 и заменяются на Google DoH; другие DNS не перезаписываются.
- Исправлена проверка RTT: небольшой HTTP-ответ дочитывается для повторного использования TLS-туннеля. Добавлены общий тайм-аут и сетевой deadline для тестового клиента.
- Ядро **1.14.4-silikbox.2**, versionCode **270**. Сохранены пакет и сертификат подписи для обновления поверх прежних сборок.
- На TECNO KL7 / Android 14 / Wi-Fi проверены: собственные тесты подключения **53/56 мс**, настоящий Android TUN, **8/8** параллельных HTTPS-запросов, **1 МиБ за 934 мс**. Сохранение настроек, профилей и ключей подтверждено сравнением баз.
- В отдельном нативном тесте на телефоне проверены все три DNS-этапа и переключение при контролируемых отказах. Первый запрос Google дал тайм-аут, повторный прошёл; доступность во всех сетях не заявляется.
- Сборка использует закреплённый gobind из репозитория без загрузки latest. GitHub CI и статическая проверка APK, включая отсутствие адресов AliDNS, пройдены.

**[Скачать и посмотреть отчёт выпуска](https://github.com/silikonoff/silikbox/releases/tag/v1.0.0-alpha3)** · **[DNS и конфиденциальность](DNS.md)**
