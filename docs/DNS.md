# DNS в silikbox

Начиная с 1.0.0-alpha3, при подключении обычного профиля адрес VPN-сервера ищется
по цепочке **Google DoH → обычный DNS Cloudflare → системный DNS Android**.
AliDNS удалён из встроенных адресов и настроек по умолчанию.

| Этап | Соединение | Предел ожидания этапа |
| --- | --- | --- |
| Google | HTTPS к 8.8.4.4 и 8.8.8.8, имя и сертификат dns.google проверяются | 2,5 секунды |
| Cloudflare | Обычный DNS к 1.1.1.1 и 1.0.0.1, UDP/53; TCP при усечённом ответе | 1,5 секунды |
| Android | DNS текущей основной сети через Android | 3 секунды |

Два адреса одного оператора проверяются одновременно. Следующий оператор
получает запрос только после отказа предыдущего этапа. Проверка сертификата
Google обязательна; для запуска не требуется сначала узнать IP dns.google.
Успешный ответ, включая NXDOMAIN или отсутствие записей нужного типа, завершает
цепочку. Отмена подключения прекращает переходы к следующим этапам.

**Cloudflare на втором этапе не зашифрован.** При использовании второго или
третьего этапа имя VPN-сервера может стать видно сети. Системный DNS Android
может использовать Private DNS, если он настроен и доступен; приложение не
предполагает, что системный резерв всегда зашифрован.

## Область действия

Резерв обслуживает только A/AAAA-запросы имён VPN-серверов, перечисленных в
текущей конфигурации. Запросы сайтов не могут использовать этот транспорт.
Удалённый DNS сайтов по умолчанию — Google DoH через VPN. Существующие правила
раздельной маршрутизации, FakeDNS и пользовательские DNS сохраняются.

В настройках DNS можно отключить резерв целиком либо только системный этап.
Явно заданные resolver-параметры outbound и полные пользовательские JSON-конфиги
сохраняют свою политику. Для сервера с буквальным IP поиск имени не нужен.
В цепочке прокси резерв назначается прямому внешнему соединению; соединения
через явно заданный detour сохраняют прежнюю обработку.

## Обновление

APK устанавливается поверх прежнего silikbox с сохранением пакета, подписи,
профилей и настроек. Старые стандартные адреса удалённого DNS-провайдера заменяются
на Google DoH. Значение `local` и прочие пользовательские DNS не перезаписываются.
Для распознавания удалённых стандартных адресов в APK остаются только SHA-256
отпечатки; сами старые адреса в коде и ресурсах не хранятся и не используются.

Работа публичных DNS зависит от сети и фильтрации. Цепочка повышает доступность,
но не гарантирует подключение при одновременной блокировке всех вариантов.
